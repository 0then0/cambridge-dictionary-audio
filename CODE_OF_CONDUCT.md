# Code of conduct

Everyone participating in this project is expected to help keep issues, pull
requests and other project spaces welcoming and useful.

## Expected behavior

- Be respectful of people with different backgrounds, experience and opinions.
- Give specific, constructive feedback about the work. Critique ideas and code
  without personal attacks.
- Respect privacy. Obtain permission before sharing someone else's personal
  information or private correspondence.
- Keep discussion relevant and follow reasonable moderation requests.

Harassment, discriminatory language, threats, sexualized attention, deliberate
intimidation and publishing private information are not acceptable.

## Reporting and moderation

Report conduct concerns privately to the maintainer at
[zheltov_pe@mail.ru](mailto:zheltov_pe@mail.ru). Include relevant links, context
and the safest way to contact you. Do not post sensitive evidence in a public issue.

The maintainer may edit or remove content, close discussions or restrict project
participation in response to violations. Responses should reflect the severity
and pattern of the behavior. Reports will be handled discreetly; information
will be shared only as needed to investigate and respond. These expectations
also apply when someone represents the project in other public spaces.
